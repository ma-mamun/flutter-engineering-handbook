# Examples

Self-contained example apps referenced by the handbook. Each lives in its own directory
with its own `pubspec.yaml` and runs standalone:

```bash
cd examples/<name>
flutter pub get
flutter run
```

An example belongs here when a point needs a whole running app to make. If a snippet
under `code/` can carry it, use that instead — snippets are analyzed by CI and stay
current with much less maintenance.
