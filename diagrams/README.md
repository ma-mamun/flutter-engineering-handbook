# Diagrams

Mermaid sources for diagrams reused across more than one page. One-off diagrams belong
inline in the page that uses them.

- `*.mmd` — Mermaid source, the file of record.
- Pages embed the same content in a ` ```mermaid ` fence; the theme renders it natively,
  so no image export step is needed.

Keep the source here in sync with the fence in the page when you edit either.
